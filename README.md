# Agora — AI MUN Learning

Agora helps Model United Nations delegates prepare at their own pace. Choose a beginner or experienced path, learn committee skills, explore a country briefing, and practice responding to Points of Information (POIs).

## Open the app

Open `index.html` in a browser. The app is a lightweight static site and needs no build step or account. It saves learning progress in the browser on the current device.

## What’s included

- Beginner and experienced delegate onboarding
- Six practical lessons on procedure, speeches, research, and diplomacy
- Country briefings for Ethiopia, Brazil, Japan, Kenya, France, India, Canada, and Nigeria
- POI practice with rotating prompts and response coaching
- Responsive layout for desktop and mobile

Country snapshots are introductory learning material. Delegates should verify current positions with official government and United Nations sources before committee.
